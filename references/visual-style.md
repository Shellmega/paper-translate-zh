# PDF 视觉基准

视觉参照：[封面](cover-reference.png)、[目录](toc-reference.png)、[正文与表格](body-reference.png)。可直接复用 [academic-print.css](../assets/academic-print.css)；若使用其他排版工具，匹配下列效果。样式可为内容长度和图表尺寸微调，不牺牲可读性。

- A4，四周约 21/17/21/17 mm；白底、充足留白。正文思源宋体约 10.3 pt、行距约 1.67；标题及表格用思源黑体。字体不可用时选外观接近且中文字符完整的替代字体。
- 封面采用深海军蓝至青绿色的顶部横条、深蓝大标题、青绿色短横线、浅灰同心圆装饰；作者与机构按原文信息排列。不要写入示例论文的标题、作者或日期。
- 目录使用蓝色标题与细分隔线，内容适合时双栏；长目录自然续页。正文一级标题深蓝并带浅色底线，二级标题深蓝；段落间距、引文、代码块保持示例的疏密。
- 表格用深蓝表头、白字、浅蓝灰交替行，跨页重复表头；图表题用蓝灰强调。公式居中并保留编号。页脚左侧为论文短题与「中文译文」，右侧为当前页／总页数。
- 最终 PDF 应呈现与参照相同的配色、字体层级和简洁学术风格。检查封面、目录、典型正文、图表、末页；避免为追求一致而压缩、裁切或遗漏内容。

使用 CSS 时，由排版程序生成 `.cover`、`.toc > .toc-list` 和 `main` 结构；给图题、表题及公式分别应用 `.figure-caption`、`.table-caption`、`.display-math`。页脚需由 PDF 引擎另行生成。样式表只提供外观，不会自动创建这些内容。
